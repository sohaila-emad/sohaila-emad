## About Me

I'm a Systems & Biomedical Engineering student at Cairo University, interested in the intersection of AI, data, and real-world applications.

I enjoy understanding the whole process behind a project: preparing the data, exploring different approaches, building the model or application, evaluating results, and figuring out what can be improved.

Currently, I'm focusing on:

- **AI & Deep Learning:** building and evaluating models for real-world problems.
- **Computer Vision:** medical imaging, image processing, and object detection.
- **NLP & LLMs:** Transformers, biomedical NLP, and neural machine translation.
- **Data Engineering:** SQL, ETL, data warehousing, and data pipeline design.
- **Software Development:** turning algorithms and ideas into usable applications.

I like projects that involve more than just calling a pretrained model or following a tutorial. The interesting part is often understanding the data, solving the unexpected problems, and making the whole system work.

## Featured Projects

### 1. English–Arabic Neural Machine Translation

**PyTorch · Transformers · NLP · Hugging Face**

A neural machine translation project built by implementing and training an encoder–decoder Transformer from scratch.

- Implemented core Transformer components, attention, and masking.
- Worked on tokenization, training, validation, and checkpoint management.
- Added checkpoint resumption to continue interrupted training.
- Uploaded the trained model to Hugging Face.

[Repository](https://github.com/sohaila-emad/en-ar-transformer) · [Hugging Face](https://huggingface.co/Sohaila052)

### 2. Knee MRI Abnormality Detection

**PyTorch · ResNet50 · Attention MIL · Medical Imaging**

Built a multi-label knee MRI abnormality detection system covering 12 abnormalities.

- Used ResNet50 for feature extraction and two-stage Attention-based Multiple Instance Learning for study-level predictions.
- Worked with DICOM medical imaging data.
- Achieved approximately **0.838 validation macro AUC** and a **0.908 competition leaderboard score** in the reported experiment.

### 3. Biomedical Named Entity Recognition

**BioBERT · Hugging Face · NLP**

A biomedical NLP project for extracting scientific entities from research text using the EMBO SourceData dataset.

- Implemented token-level classification with BIO tagging.
- Handled subword-label alignment and biomedical text preprocessing.
- Evaluated predictions using precision, recall, F1-score, and accuracy.
- Achieved a **0.8335 validation F1-score** in the reported experiment.

[Model and project](https://huggingface.co/Sohaila052/biobert_ner)

### 4. Hybrid AI Pneumonia Detection

**PyTorch · U-Net · Faster R-CNN · XGBoost**

A medical imaging pipeline combining deep learning and classical machine learning.

- Used U-Net for lung segmentation.
- Applied Faster R-CNN to localize suspected pneumonia regions.
- Extracted GLCM radiomic features and explored XGBoost, Random Forest, and SVM classifiers alongside the detection branch.

### 5. SQL Data Warehouse

**SQL Server · T-SQL · ETL · Medallion Architecture**

Designed a data warehouse workflow using ERP and CRM source data.

- Structured the architecture into Bronze, Silver, and Gold layers.
- Implemented SQL-based data cleaning, transformation, and deduplication.
- Used stored procedures and window functions, including `LEAD()`.
- Documented the warehouse architecture and transformation workflow.

### 6. 3elty — Family Health App

**Web Development · Healthcare Technology**

An Arabic-first family health application concept focused on organizing family health information in one place.

- Focuses on making health records and medical information easier to manage.
- Addresses the challenge of scattered medical documents, reports, prescriptions, and vaccination records.
- Connects my interest in healthcare technology with practical software development.

### 7. Signal Processing & Interactive Visualization

**Digital Signal Processing · Python · DFT/IDFT · Tkinter**

Developed interactive tools for exploring and processing signals.

- Built a signal equalizer using Discrete Fourier Transform and Inverse Discrete Fourier Transform concepts.
- Added interactive frequency-band controls to explore how modifying frequency components affects a signal.
- Developed an ECG live filtering and visualization tool with band-pass and notch filtering.
- Implemented interactive controls for signal parameters and analysis.

### 8. Sinus Endoscopy Image Classifier

**Python · PyQt5 · OpenCV · ResNet18**

Developed a GUI application for classifying sinus endoscopy images.

- Integrated a ResNet18 CNN model into an interactive desktop application.
- Achieved **92% validation accuracy** in the reported experiment.
- Combined computer vision with an application designed around a healthcare use case.
